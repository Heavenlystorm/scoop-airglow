# Airglow Scoop bucket

Manifests for [Airglow](https://github.com/Heavenlystorm/airglow), free RGB, fan and sensor control for Windows.

```powershell
scoop bucket add airglow https://github.com/Heavenlystorm/scoop-airglow
scoop install airglow
```

`scoop update airglow` picks up new versions. The manifest is rewritten by Airglow's release workflow on every stable
release; `scoop checkver airglow` can also bump it by hand.
